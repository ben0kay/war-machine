# DBG-Z0 — detachable first-person test zombie spawner

**Implemented in source (2026-10-31); local Godot C# build and F6 test pending.** This temporary helper belongs in `DEBUG/ZombieSpawner/`, not the Player or gameplay zombie source. `FirstPersonWorld.tscn` instances one `DebugZombieSpawner.tscn` under `DebugUIRoot`. The inherited top-down `World.tscn` does not include it. `FirstPersonWorld.InitializeControls` optionally binds the helper after terrain, players, corpses, audio and vision debug are initialized, leaving the shared world controller untouched.

**Use:** With gameplay mouse captured, tap **0** (top-row or keypad) while looking at walkable terrain within 70m. One key event queues one physics tick; a camera ray locates the aimed spot, terrain height and ground support are verified, and a real zombie capsule is checked for overlap. Invalid sky, wall, roof, steep/blocked ground or positions within 3m of the player are rejected with an Output message. On success: normal Zombie.tscn 90%, fast Zombie_002.tscn 10%, independently sampled for every successful attempt; it is a probability, not a guaranteed 9/1 order. Each joins the ordinary Zombies world root, binds the actual player target, terrain sampler, sound hearing, corpse owner, and F7 vision/debug register, with unique RNG seed. The cap is 20 **live debug zombies**, not total lifetime spawns; normal death removes actors via their original lifecycle.

**Isolation:** no idle `_Process`, no continuous physics, only keyboard event and one deferred-to-physics query per press. `Enabled`, `MaxActiveDebugZombies`, `AimRange`, and `RunnerChance` are exported on the debug scene. Uncheck Enabled in its Inspector to disable, or remove `DebugUIRoot/DebugZombieSpawner` from `FirstPersonWorld.tscn` to unplug; the FPS lookup is `GetNodeOrNull`, so no code edits required. Builds outside debug mode do not activate it. Spawned zombies use the regular root and persist for the current session even if the helper is removed. F1 and uncaptured/blocked gameplay don't spawn.

**Local acceptance:** build, F6 FPS, press 0 while aiming at open ground 5–30m away; repeat to see normal/fast selection, check F7 vision cones and zombie attacks/hearing/corpses, verify F1 open/sky/roof/too-close rejection, hold 0 without repeat, and test cap. No changes to runtime zombie masters, world startup spawns, input maps or gameplay collision masks.
