# Player-centred visibility fog

PlayerDistanceFog owns one full-screen depth overlay for the active top-down presentation. It reconstructs opaque surface world positions and fades them by horizontal distance from the player, with broad stationary edge variation. Terrain, opaque zombies and props progressively disappear into grey-blue fog. Perspective and orthographic views use the same inverse camera matrices; this is a world-space radius, not a screen vignette.

Defaults in ENVIRONMENT/Configuration/GameplayEnvironmentMaster.tres: enabled, clear to 24m, full fog at 48m, opacity 1, edge variation 2m, color (0.39,0.46,0.48). Full radius is clamped to at least clear radius + 1m. Top-down tuning panel exposes enabled, both radii, opacity, variation and tint; Copy settings includes all six values (color as RGBA array). The daytime tint is independently adjustable; the shared solar atmosphere now blends it with DuskFogColor and NightFogColor. TimeResponsiveFog disables this blend when a fixed tint is wanted.

WorldController creates the owner under SystemsRoot/EnvironmentRoot; its camera-local DistanceFogOverlay is intentionally a camera child for correct fullscreen culling and lifetime. It has no physics, casts no shadows and draws late in the transparent pass (priority 127), blending directly over the scene without a second viewport or screen-color copy. Interface controls are unaffected. FPS now overrides initialization with its own profile/controller using the same overlay in optional camera-distance mode; sky/weather remain unchanged.

No C# process/physics callbacks. Player PositionChanged updates one uniform while moving; settings uploads happen on initialization/UI edits and changed daylight signals from the existing Sky3D clock. OFF or zero opacity hides the overlay (no draw) and removes the position subscription. Reactivation explicitly refreshes the center. Exit removes subscription and frees the camera overlay. Enabled fog costs one depth read and simple arithmetic per screen pixel; no enemy scans, rays, FogVolumes or volumetric simulation. Existing vegetation/weather/enemies keep their own activation logic.

This is visual atmosphere, not explored-map fog of war, enemy spawning, AI line-of-sight or simulation culling. Hidden zombies continue their existing behavior and become visible as they approach. Depth comes from opaque surfaces: transparent effects/glass can inherit fog distance from opaque geometry behind them, especially at silhouettes. A rectangular prefab or transparent fading effect is not independently tracked. Radius boundaries have soft variation, not animated wisps. Near-camera obstruction fading remains separate.

Source review: Godot advanced post-processing guidance for reverse-Z depth reconstruction/fullscreen culling. No global rendering/project settings changed. ## FPS camera-distance mode

Initialize(..., cameraDistance: true) selects spherical 3D distance from the renderer camera instead of player XZ distance. Default false preserves top-down behavior. The shader supports both projection types; FPS has no position subscription, since camera position comes directly from render matrices. FPS controller forces opacity 1 and edge variation 0 so its linked far clipping plane stays concealed. Fog is a late depth overlay, not volumetric fog; transparent surfaces still use opaque depth behind them, a known limitation. The horizon remains covered; FPS reveals Sky3D above it using FpsSkyFogOpacity. Fog tint now follows shared solar elevation even though FPS retains its own distance profile.

DEBUG/TEST/FirstPerson/ENVIRONMENT/FirstPersonFog owns the profile/UI and linked camera Far; shared top-down fog does not change camera Far. The shared left-side overlay exposes start/end, cull buffer, enabled and colour plus copy. Changing end adjusts Far = effective end + buffer (minimum 8m). Disabling fog restores the prior camera Far. Frustum culling clips distant geometry; existing MultiMesh chunk bounds can still straddle the cutoff and submit some hidden instances. This does not unload chunks, stop AI, adjust physics, or guarantee shadow costs disappear. No measured performance claim. Local build/shader/visual checks pending.
