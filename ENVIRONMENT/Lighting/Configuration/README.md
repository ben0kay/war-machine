# Lighting master configuration

`LightingMaster.tres` is a placeholder Inspector resource backed by `../LightingSettings.cs`. It defines future local-light enable, a transient-light budget and rifle muzzle-light defaults. **It does not affect the world until a runtime consumer is implemented (LI0).** Read `../IMPLEMENTATION_PLAN.md` before connecting it. Campfire configuration will be decided separately when a campfire exists.
