# Campfire local illumination — future idea only

**Not authorized for implementation yet.** A reusable campfire prop should emit persistent warm, orange light from an OmniLight3D above its flames. While burning, lightly randomize brightness/colour/very small range variations to imitate moving flames; when extinguished or unloaded, turn the light and any flicker updates completely off. Start with a modest 6–10m illumination range, soft glow on nearby grass, trees, player and volumetric haze; consider optional nearby shadows only after performance measurements. Flames, smoke, embers, fuel, ignition/extinguishing, sound, damage and saving are separate future tasks. Campfire visuals and prop ownership should follow `WORLD/Content/`; generic lighting utilities belong in `ENVIRONMENT/Lighting/Shared/`. No campfire scene/assets/settings or game-world placement are created by this scaffold.
