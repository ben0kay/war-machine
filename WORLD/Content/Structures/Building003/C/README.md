# C — Building003 procedural mesh

`Building003Mesh.cs` builds the provisional fuel station, shop interior, closed garage shutter, forecourt/canopy/pumps and collision in **Godot C#**.

`C/` is strictly the temporary procedural **mesh** folder. Future imported GLB models live in `../Artwork/`; inspector settings live in `../Configuration/`. Shared geometry helpers under `../../Shared/C/`.
