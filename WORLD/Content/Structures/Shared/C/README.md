# C — StructureGeometry

`StructureGeometry.cs` is an allocation-light, one-time Godot C# procedural mesh helper: shared unit box mesh, per-prefab materials, optionally collidable box parts, solid wall segments with real openings, cylinders and pitched gable triangles.

Called by the Building002 and Building003 `[Tool]` generators. No runtime scene searches, physics ticks or automatic placement.
