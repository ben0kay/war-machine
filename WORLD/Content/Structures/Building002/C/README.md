# C — Building002 procedural mesh

`Building002Mesh.cs` generates the temporary low-poly ranger lodge, interior furnishings, open door/windows, veranda and static collision in **Godot C#**. **C/ is for mesh generation only**, not imported artwork or independent gameplay systems. Shared primitives: `../../Shared/C/StructureGeometry.cs`.

One-shot `[Tool]` generation; no per-frame processor. Actual future building model files belong in `../Artwork/`.
