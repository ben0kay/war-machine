## Solid ramp collision correction (current)

The earlier ramp surfaces were emitted with the opposite winding from Godot's clockwise front faces. Double-sided art could conceal this while one-sided trimesh collision did not provide the intended upward-facing support. Asphalt shoulders now use eight closed convex wedge volumes (1mm margin), and the rear-door ramp uses a closed convex wedge too. Their top edges meet the existing slab; outer toes and bases extend slightly below the graded ground so there is no new toe lip. Render triangle winding is corrected independently. This replaces the former CreateTrimeshShape ramp collision; main slab/wall/car colliders and player movement are unchanged. Default shoulder grade is about 10 degrees. Shapes are created once, with no extra runtime collision polling.
