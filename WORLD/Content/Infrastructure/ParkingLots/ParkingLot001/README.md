# ParkingLot001 — reusable parking foundation

Current default: **56 x 36m main apron, 14 marked bays, 8m-wide / 6m-long driveway**, 0.12m asphalt thickness and 0.8m sloped perimeter shoulders. Instanced by ConvenienceStoreSite001 in the active WORLD/World.tscn and inherited FPS test. Source/build/visual acceptance remains local.

ParkingLot001.tscn uses the one-time [Tool] C/ParkingLotMesh.cs builder and Configuration/ParkingLotMaster.tres. Configuration/ParkingLotSettings.cs is a [Tool]/[GlobalClass] resource. Artwork/ remains for future assets. Width/depth/count/colours/curbs are Inspector-editable; reopen/reinstance to rebuild after changing the master. No polling or live rebuild loop.

Local -Z faces the store and +Z leads to the road. Root Y is the foundation bottom; walkable asphalt is 0.12m above it. There are 14 passive Generated/Markers/ParkingSpots/Bay_01..Bay_14 markers, and Entrance/Storefront/RoadConnection markers. Bay count supports up to 16, still capped to fit with 2m side margins. The lot has no built-in cars, lamps, building, actor spawning, light or audio logic; site composition owns those separately.

The apron and driveway use static layer-1 collision. Paint is non-colliding. Continuous sloped asphalt shoulders around the complete apron+driveway outline bridge the 12cm vertical slab edge to root-level terrain; the default slope is about 8.5 degrees. The central entrance strip has a 2mm lip. Raised side sidewalk curbs remain intentional; use the central opening. All mesh/collision construction runs once and then sleeps.

World/VillageLayout measures the complete generated site bounds including shoulders, surveys the full platform, and feeds existing terrain/grass/pine/rock reservations. WORLD/Generation/VillageTerrain grades native terrain beneath it; no terrain editing occurs in this prefab and no saved terrain rebake is needed. Changes to prefab dimensions require matching site car/lamp/store/marker transforms; the current site is aligned for this default.
