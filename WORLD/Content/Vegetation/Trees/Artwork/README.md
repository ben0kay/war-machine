# Tree artwork

Place authored tree assets here later (`.glb`, models, material/texture resources). The current preview is generated from C# in `../C/`; this folder intentionally contains no 3D models.

For static placement, assign imported Mesh resources to `../Configuration/TreeMaster.tres` -> `ImportedMeshes` to override generated oak meshes. Interactive/choppable trees will use a future near-player scene system.
