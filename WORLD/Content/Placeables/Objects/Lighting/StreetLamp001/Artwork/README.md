# StreetLamp001 artwork

The lamp is currently original procedural low-poly geometry: tapered metal post, rigid base, projecting arm, rectangular metal luminaire and slightly emissive LED underside. No texture imports, light-projection images or imported GLBs are required. The LED panel emission is **not** a light source by itself; the scene's real `SpotLight3D` and `OmniLight3D` supply illumination. Imported replacement art can preserve the light-head coordinates/scene nodes and collision.
