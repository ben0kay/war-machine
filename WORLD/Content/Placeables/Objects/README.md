# Objects — cannot be picked up

Objects are world assets the player cannot physically lift. Some may still operate (cupboards, generators) and others are entirely fixed/inert. The first **mesh-only** example is [Bookcase001](Furniture/Bookcases/Bookcase001/README.md): fixed, non-interactive and unbreakable with open shelves.

Future examples: tables, cupboards, large furniture, generators and cars. Existing `WORLD/Content/Objects/Cars/Car001/` remains at its old path, not migrated or copied. See [Placeables foundation](../README.md).
