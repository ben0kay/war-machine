# Rock shader

Stone.gdshader uses shared world-space triplanar textures and normals; packed normal alpha supplies roughness. Upward-facing moss and dampness are adjustable without regenerating meshes. Parameters are configured by StoneMaterial.tres / RockMaster and runtime F9 controls. No TIME animation, displacement, transparent rendering or per-frame CPU work. Source demo textures and licence remain in demo/assets/textures.
