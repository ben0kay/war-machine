# PoliceStation001/Configuration

`PoliceStationSettings.cs : StructureSettings` provides independently tunable storey heights, neutral shell materials and optional terrain-supported ground slab. `PoliceStationMaster.tres` is the shared default resource referenced by both prefab root and `StructureVisibility`. The horizontal floor plan is deliberately fixed at 48×64m for PS0; changing the floor elevation resource requires scene reopening to rebuild generated shapes.
