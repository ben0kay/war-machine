# Reusable infrastructure

World surfaces and fixed infrastructure reusable across many sites: parking lots, short road segments, paths, curbs and similar ground assemblies. Not owned by a specific convenience store or building.

Start with [ParkingLot001](ParkingLots/ParkingLot001/README.md). The infrastructure folder is deliberately separate from `Structures/` (building shells) and `Objects/` (individual assets). The static layout should be built once with no idle processing.
