# Parking-lot prefab library

Each lot is an independently reusable scene with its own procedural geometry, materials and configuration. A site may instantiate a lot and place cars/lights at predefined markers; the lot must **not** hard-code a store, car or lamp dependency.

[ParkingLot001](ParkingLot001/README.md) is now the standalone PL0A parking foundation (source implemented; Godot validation pending).
