# Cars

Reusable stationary car props, starting with [Car001](Car001/README.md). **Car001 now uses a shared low-poly GLB** and a small C# scene adapter for colour, dimensions, static collision and its instance-adjustable driver's door. It is not drivable and does not tick while idle. See the separate [modular variants plan](Car001/MODULAR_VARIANTS_PLAN.md) for future damaged/part-removal states.
