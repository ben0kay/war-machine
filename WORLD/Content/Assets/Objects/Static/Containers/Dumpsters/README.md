# Dumpsters

Industrial, large fixed steel waste containers. [DumpsterBin001](DumpsterBin001/README.md) is an original approximately **3.48m-wide, 2.55m-tall** dark forest-green dumpster with two black lids and **no wheels**. It has its own GLB, canonical .tscn, size master and SOC0 static AutoBox collision. Appears automatically in F1; not permanently placed, not lootable or movable.
