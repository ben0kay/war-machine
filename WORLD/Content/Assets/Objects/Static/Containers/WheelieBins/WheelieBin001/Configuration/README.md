# Wheelie-bin size master

`WheelieBinMaster.tres` is the existing `PlaceableSizeSettings` type with `SizeMultiplier = Vector3(1,1,1)`. X, Y and Z are relative size multipliers (not metres). `PlaceableVisual` scales `Model` and builds the matching SOC0 AutoBox once per active scene instance. No custom generator or runtime polling.
