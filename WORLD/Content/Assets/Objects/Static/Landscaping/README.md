# Landscaping — intentionally placed ornamental static objects

This folder is for **authored, arranged garden/roadside landscaping objects**, distinct from procedurally spawned natural vegetation in `VEGETATION/` and `WORLD/Content/Vegetation/`.

- [Hedges/Hedge001](Hedges/Hedge001/README.md): clipped rectangular hedge GLB with size master, visual-only; approximately 4.8×2.14×1.27 metres.

Do not add these models to tree/grass/rock chunk placement automatically. Their object catalogue scenes can later be instanced into sites or gardens under a separately approved scene-assembly step. Static classification does not itself add physics.
