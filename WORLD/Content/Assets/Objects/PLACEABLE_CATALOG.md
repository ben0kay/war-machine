**How to resize:** Edit `SizeMultiplier = Vector3(1, 1, 1)` in an individual master's `.tres`. X is width, Y is height/thickness, Z is depth/length **relative to the original model**. For example, `Vector3(1.2, 1, 1)` widens the corresponding model 20%. Masters affect all default instances; override with a duplicate settings resource for specific instance variation. These values are **not absolute metres**. Imported GLB art is never rewritten by sizing.

**Visual material variations:** Bed001 shares one GLB across four bedding options; Table001 shares one GLB across three wood finishes. Bed001 has, 7 material surfaces total, 2 per-instance material overrides only. Table001 has 4 surfaces and 3 material overrides per finish. No runtime procedural mesh build.

**Preview:** F6 `WORLD/World.tscn` → F1 → select any canonical `PlaceableVisual`-based asset under Static/ or Props/, including Hedge001, or one of the auto-discovered bed/table enum variants, spawn and compare. The imported pine is a high-detail prototype and should not replace MultiMesh forest trees without LOD/profiling. Size changes show in **newly spawned/reloaded** previews.
