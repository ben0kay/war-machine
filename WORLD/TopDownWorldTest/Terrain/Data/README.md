# Preview-only native Terrain3D data

Generated `.res` region(s) belong here, never in the normal world's terrain folders.

This environment cannot run Godot/.NET, so native data has not been generated or committed. Run `../BakePreviewTerrain.tscn` once from the Godot .NET editor (F6), or follow the preview root README command. The baker refuses any existing `.res` files. Gameplay only loads this directory and never creates or regenerates terrain.
