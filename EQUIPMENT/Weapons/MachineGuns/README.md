# Machine guns

Independent firearm scenes using `EQUIPMENT/Weapons/Shared/FirearmController.cs` and `FirearmSettings`. Each owns only its replaceable model, muzzle placement and stats.

- [MachineGun_001](MachineGun_001/README.md) — first 600 RPM low-poly automatic light machine gun, configurable spread and a four-slot tracer pool.

Weapon switching/inventory is **not** implemented in this folder.
