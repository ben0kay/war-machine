# Tools — future handheld items

Reserved for tools such as `Axes/Axe_001/`, `Pickaxes/Pickaxe_001/` and repair/construction tools. **No tool code or models yet.** Create concrete folders as needed.

Use the same structure as rifle types: item root scene, `C/` for **Godot C# procedural mesh generation and behaviour**, `Artwork/` for eventual imported models, `Configuration/` for an item master resource, and an item README.

Share lightweight equip/hold contracts with [EQUIPMENT/Shared](../Shared/README.md) when relevant; do not couple tools to firearms or add a full inventory framework before it is needed.
