# Shared equipment — reserved

When needed, this folder will own **minimal reusable** hand-equipped object interfaces, attachment/equip/unequip contracts and actor-neutral helpers.

No generic equipment manager, inventory framework, idle polling or complex inheritance hierarchy is justified by the first rifle. Create shared code only when there is concrete reuse; currently **documentation only**. Item-specific C# procedural mesh generation belongs in that item's `C/`, not here.
