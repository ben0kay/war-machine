# Robot_001 artwork — generated materials

`Shaders/` and `Materials/` contain Godot-native procedural surface shaders and reusable `.tres` material presets for MAT1. No external textures or GLB assets needed. Future imported armour normal/roughness/albedo textures can go here, replacing these placeholder procedural finishes without replacing `Robot_001.tscn`, rig sockets, patrol, scanning or collision.
