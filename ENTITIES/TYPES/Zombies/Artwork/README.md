# Zombie Artwork

Future imported zombie models belong here. Current procedural geometry and rig construction live in ../C/ZombieMeshBuilder.cs; behaviour/settings live in the zombie root folder.

## Shared procedural finishes (ZMAT0)

Current zombie texture variation is generated in code by `../C/ZombieAppearance.cs` and cached for all standard zombies and Zombie_002 runners. No imported PNG needed. It includes clean and subtly blood-stained face/shirt/trouser variants. Future handcrafted albedo, normal and roughness textures can live here if desired.
